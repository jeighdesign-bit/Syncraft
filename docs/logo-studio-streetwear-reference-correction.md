## Visual construction to preserve

| Original visual feature | Automatic direction now encoded |
| --- | --- |
| Tall, dense ornamental words with narrow internal spaces | Condensed letters, waisted stems, inset cuts, coordinated flared terminals and tight optical spacing |
| Whole words sculpted into bowed or pinched silhouettes | Arched envelopes adjust actual letter heights and outer strokes, instead of rotating unchanged characters on a curve |
| Sharp italic script with strong extended strokes | Chisel-cut joins, tall ascenders, pointed swashes, extended crossbars and controlled underlines |
| Gold/silver faces with deliberate shade bands | Broad hard-edged bevel planes, inset highlights, stepped shadow bands and one consistent extrusion direction |
| Contrast keylines surrounding a cohesive silhouette | Dark separating base plus controlled accent keylines; fine outer edge and open counters |
| Black or charcoal fields | Default uniform `#191919` background for this style, with selected colors taking priority |
| Monochrome examples with no depth | Flat explicitly removes shading but retains bespoke letter construction |

This is a manual visual analysis translated into generation instructions. The reference image files are not embedded in provider requests, shipped in public assets, or used to copy the reference wording, signatures or contact information. The image model still needs a live visual check; instruction coverage alone cannot establish fidelity.

## Implementation

- `logoStreetwear.mjs` centralizes the shared visual contract, automatic background and color treatment.
- The shared profile no longer enumerates all ten lettering genres. The selected construction comes from its own validated control, so unrelated font directions do not compete with it.
- Both baseline and compiled prompts include the same visual contract and defaults. Explicit Flat, Straight, Single and color selections still override automatic treatment.
- Blank optional brief + brand/controls returns a local `style-preset` plan in the Text planning path. It uses typography-specific structural routes, preserves the blank raw brief, and makes no general concept-planner call. Image generation continues through the existing Studio provider and billing flow. A supplied optional brief still uses the existing planner.
- Profile version is `art-direction-6`; explicit variations are `logo-variation-5`. Auto variations preserve accepted images and edits.
- Three first-pass Streetwear examples are archived in `logoExampleStreetwear.mjs` and withheld from the published collection until the user reviews replacement Studio outputs. Existing user projects and generated jobs are preserved.
